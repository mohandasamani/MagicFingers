# Dedos Mágicos — versão instalável e offline

Arquivos: index.html, sw.js, manifest.json e ícones. Envie todos para a raiz de um repositório no GitHub.

1. Crie um repositório público no GitHub (ex.: `dedos-magicos`).
2. Em "Add file → Upload files", envie todos os arquivos desta pasta.
3. Em Settings → Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`, e salve.
4. Em 1 ou 2 minutos o app fica em `https://SEU-USUARIO.github.io/dedos-magicos/`.
5. Abra esse endereço no Chrome do celular e toque em ⋮ → "Adicionar à tela inicial" (ou "Instalar app").

Depois da primeira abertura, o app funciona sem internet.
Os riffs desta versão ficam salvos no celular. Para trazer os riffs da versão do Claude, use Ajustes → Exportar backup lá e Ajustes → Importar backup aqui.
