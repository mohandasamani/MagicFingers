# Dedos Mágicos — versão instalável e offline

https://mohandasamani.github.io/MagicFingers/

1. Abra esse endereço no Chrome do celular e toque em ⋮ → "Adicionar à tela inicial" (ou "Instalar app").

Depois da primeira abertura, o app funciona sem internet.
Os riffs desta versão ficam salvos no celular. Para trazer os riffs da versão do Claude, use Ajustes → Exportar backup lá e Ajustes → Importar backup aqui.
